# Neural-Networks-Image-Classification

Acest proiect exploreaza performanta diferitelor arhitecturi de retele neurale (MLP, CNN si ResNet-18) pe doua task-uri distincte de clasificare a imaginilor: 
1. **"Vai de pielea mea"**: Clasificarea alunitelor dermatoscopice (7 tipuri de leziuni, set puternic dezechilibrat).
2. **"You're on candid camera"**: Recunoasterea expresiilor faciale (7 emotii de baza).
